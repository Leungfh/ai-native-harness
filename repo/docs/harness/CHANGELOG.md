# 项目版本与变更记录

已有正式更新日志的项目可在此填写其路径，以已有位置作为唯一正式记录。业务版本遵循目标项目约定。本文件记录目标项目自身的变化。

| 项 | 项目填写 |
| --- | --- |
| 正式更新日志路径或链接（使用本页时填本页路径） | |
| 版本规则 / 标签规则 / 维护人 | |

## 待发布

按用户或操作人员能感知的变化记录，每项连回 Issue、PR 和想法 ID（如有）。兼容性变化要给出迁移或升级动作。使用目标项目已有的分组；没有约定时可用「新增、修复、行为变化、迁移」。

| 类型 | 对使用者的影响 / 升级动作 | Issue / PR / IDEA |
| --- | --- | --- |
| | | |

## 发布后归档

发布负责人将本次已发布条目从「待发布」移至以真实业务版本和日期命名的新段落，并在工作簿关联同一发布单。若采用语义化版本，按对外兼容性决定主、次、修订版本。下面是可重复复制的字段，项目接入时保留模板或换成既有日志格式。

| 版本记录项 | 本次填写 |
| --- | --- |
| 业务版本 / 发布时间及时区 / 发布负责人 | |
| 标签 / 提交 SHA / 发布产物标识 | |
| 用户可见变化 / 升级或迁移说明 | |
| Issue / PR / 版本发布单（含观察及恢复记录） | |
| 最终状态 / 回滚后实际运行版本（适用时） | |
| 后续改进 Issue / 负责人 / 复查点 | |
