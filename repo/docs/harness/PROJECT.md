## 在干净环境复现一次

在下表登记经核实的项目原生命令、依赖和目测结果，并把自动化步骤接入仓库根目录的 `harness.config.json`。已有流水线的语言版本、私有依赖配置或服务容器应在项目 CI 中复用。该脚本使用 Python 3.9 或以上版本。

适配验证入口：先在根目录运行 `python3 scripts/harness.py doctor` 检查结构和配置，再运行 `python3 scripts/harness.py check`。后者须接入项目的实际测试。需要跳过 lint 或 build 时，在配置中记录与该项目有关的原因，并在 PR 中复核。
